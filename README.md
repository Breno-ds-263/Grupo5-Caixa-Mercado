# Grupo5-Caixa-Mercado


Funcionalidades Implementadas:
- Nome do produto;
- Preço do produto;
- Quantidade desejada;
- Cálculo do valor total da compra;
- Cálculo de descontos.

Foi implementado um sistema de descontos para clientes. 
Quando o valor total da compra for superior a R$ 100,00, o cliente recebe 10% do valor em descontos.

Organização das Branches

Branch	Responsabilidade:

- Entrada do nome do produto ( branch-gustavo) - Gustavo;
- Entrada do preço do produto (branch-vanessa) - Vanessa;
- Entrada da quantidade do produto (quantidade) - Naiara;
- Cálculo do valor total da compra (breno-preco-total) - Breno;
- Implementação da regra de 10% de pontos para compras acima de R$ 100,00 (main) - Breno.
